# Reality evidence sources

Last Known Book distinguishes **source evidence** from **evidence generated by this implementation**.

## LKB-001 — MINT_A_PAIR + indexer lag
Source: `shreyas-sovani/Window`, commit `f1ac6e7a640cba7623cc4c3057d675f957121a02`, `src/domain/AGENTS.md`.

The public source records a real Shannon Call that was confirmed on-chain while the application verification path remained unavailable, then documents that the fill used `MINT_A_PAIR` semantics and required corrected escrow accounting. The source redacts the middle of the transaction hash; Last Known Book preserves that limitation rather than inventing a full hash.

## LKB-002 — Resting SELL escrow lifecycle
Source: `Techkeyy/villa`, `docs/INVENTORY_LIFECYCLE.md`.

The source records a real Shannon lifecycle in which visible YES inventory moves into venue escrow while a sell rests, returns on exact cancellation, and the complete set is subsequently reconciled back to collateral. Full source transaction identifiers are preserved in the LKB-002 fixture.

## LKB-003 — Expected vs actual execution
Source: `tang-vu/outcome-guard`, `docs/evidence/execution-receipt.json`.

The source records a real Shannon execution where requested price/quantity, actual average fill, position delta and collateral spent are all reconciled. The source transaction identifier is preserved in the LKB-003 fixture.

## Truth boundary
These sources prove that the incident classes occurred on Shannon. They do **not** prove prevalence, willingness to pay, production reliability, or that Last Known Book itself originated the transactions.
